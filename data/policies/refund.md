# Refund Policy

## Who can be refunded
Refunds are available only for orders that have been **delivered**.
- Orders that are placed or shipped but not yet delivered cannot be refunded yet.
- Cancelled orders cannot be refunded, because the customer was never charged.

## Refund windows
The window starts on the **delivery date** and is counted in whole days.
A request on the last day of the window is still accepted.

| Item category | Standard window | VIP window |
|---|---|---|
| Clothing | 30 days | 30 days |
| Home | 30 days | 30 days |
| Electronics | 14 days | 21 days |
| Gift cards | Not refundable | Not refundable |

If an order contains items from more than one category, the **shortest** window
applies. An order containing a gift card is not eligible for an automatic refund.

## Refund amounts
- A refund can never exceed the order total minus anything already refunded.
- Partial refunds are allowed (for example, one damaged item out of several).
- An order that has been fully refunded cannot be refunded again.

## Approval
A refund needs approval from a human agent if the **total refunded on that order,
including the new refund,** would be more than $200.00 (20,000 cents). The automated
agent must never issue such a refund by itself. Splitting a large refund into several
small ones does not avoid this rule.

## Defective items
If a customer says an item arrived defective or damaged, the automated agent does not
decide the claim. It should escalate to a human, whatever the refund window says.
